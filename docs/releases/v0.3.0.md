## New

- **Logo:** bunny ears peeking out of a folder – in the header (in the colours of the selected skin), as favicon
  and in the README.
- **Size per container:** the folder details show next to every container and stack under "Used by" how big
  the path it mounts is – e.g. `jellyfin/config` 1.1 GiB, `jellyfin/cache` 7.2 GiB. Measured in the same pass
  as the folder, without a second pass over the disk. Also in the API (`size_bytes` on each reference) and for AI
  agents (`get_folder`).

## Fixed

- Portainer stacks no longer show "relative path … skipped, because the compose folder is unknown" – for
  example for `env_file: stack.env`, which Portainer itself writes. Relative paths in Portainer stacks point into
  Portainer's own data folder, never into a scan root, so they are skipped silently. Dustbunny reads the stack's
  variables through the Portainer API, as before. (Also in 0.2.1.)

## Changed

- **No more pip in the image.** The `python:3.12-slim` base image ships pip 25.0.1 and will keep it: Python 3.12
  only gets security fixes, and the bundled pip goes with it. Dustbunny doesn't need pip at runtime, so the
  image no longer contains it – an old pip can't show up in vulnerability scans any more. The image itself is
  built with the newest pip.

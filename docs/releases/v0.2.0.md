## New

- **AI agents (MCP):** Claude, ChatGPT, Grok, Claude Code and other MCP clients can ask Dustbunny which folders
  are orphaned, why, and how big they are, and can start a scan. Off by default; switch it on with
  `MCP_ENABLED` and a secret `MCP_TOKEN`. Agents only read – with `MCP_ALLOW_CHANGES` they may also ignore
  folders, never more. See "AI agents (MCP)" in the README.
- **Sorting** of the folder list by name, size, created and last change.

## Improved

- The image is now also built for every pull request, so updates of the build tools are tested before they
  reach `main`.
- Up-to-date dependencies (FastAPI, Pydantic, Apprise, uvicorn) and GitHub Actions.
- README: running behind a reverse proxy – keep the port private, login, proxy headers, sub-paths.

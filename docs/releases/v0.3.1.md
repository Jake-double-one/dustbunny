## Fixed

- The version at the bottom of the page matches the release again. Images built from `main` before a release
  was tagged showed the previous release plus a commit count (e.g. `v0.2.0-2-gf8badf3`). The version now always
  comes from the project itself: a release shows `0.3.1`, a development build `0.3.1+1a2b3c4`. A release tag
  that doesn't match the project version stops the build.

## Changed

- `ghcr.io/jake-double-one/dustbunny:latest` is now the newest **release**. Until now it followed every change
  on `main`. Development builds are available as `:main`. Nothing to do if you use `latest` – the next pull
  brings 0.3.1.

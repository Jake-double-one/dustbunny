## Fixed

- Portainer stacks no longer show "relative path … skipped, because the compose folder is unknown" – for
  example for `env_file: stack.env`, which Portainer itself writes. Relative paths in Portainer stacks point into
  Portainer's own data folder, never into a scan root, so they are skipped silently. Dustbunny reads the stack's
  variables through the Portainer API, as before.
